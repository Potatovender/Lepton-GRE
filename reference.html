Lepton Reference

Look up a function, learn a data type, or find the syntax for your next graph.

These examples use Text view. Paste a complete scene and choose Apply to graph, then switch to Standard to edit its blocks. For a walkthrough, open What do I do? in the grapher.

expression wave = sin(x)+cos(y)
colour ocean = 40+30*x~130+40*x~210
draw(wave) {colour=ocean}

Lepton evaluates a value at each pixel, then maps that value to colour. In a colour or transparency formula, x receives the draw result; y stays the vertical graph coordinate. A draw is a coloured field, not an automatic line plot. To draw a curve, restrict a narrow band around it.

Values & animation

Expression

A named formula evaluated at the graph coordinates x,y. Use its ID without parentheses.

expression radius = hypot(x,y)
expression rings = sin(4*radius)

Function

A reusable formula with named inputs. Inputs are local: a parameter takes precedence over an outer value with the same name. Calls must supply the declared number of inputs.

function distance(a,b) = hypot(a,b)
expression circle = distance(x,y)-3
function offset(a,b) -> point = [a+1,b-1]

Slider

An editable value with minimum and maximum endpoints. Drag the handle or enter a value; changing a slider updates the graph.

slider amount = 5 {range=0~10}

Time

Use local Play or Play all to animate. Bounded time bounces; bounded looped time wraps; unbounded time keeps increasing. Speed is units per second and may reference values, but must resolve without coordinates. The FPS counter appears beside playback.

time bounded t = 0 {range=0~10, speed=1}
time bounded_looped phase = 0 {range=0~6.283185, speed=0.5}
time unbounded clock = 0 {speed=1}

For a seamless loop, use matching values at the endpoints, such as sin(phase+x) with phase running from 0 to 2*pi.

Colour & drawing

Colour (RGB / HSV)

Three formulas separated by ~. RGB channels clamp to 0..255. HSV hue wraps every 360 degrees, independent of angle mode; saturation and brightness clamp to 0..1. Both spellings, colour and color, work.

colour warm = 255~140+40*x~80
colourhsv spectrum = 180+90*x~0.8~1

Boundary

Draw only where the boundary formula is greater than or equal to zero. Use {when=lte} for less than or equal to zero. Boundaries use graph coordinates, not the mapped draw value.

boundary disc = 9-x^2-y^2
boundary below = y {when=lte}
boundary halfDisc = and(disc,below)

Use and, or, not, xor, or xand to combine signed boundaries. See the math reference below for the exact formulas and zero-edge behavior.

Transparency

A formula clamped to 0..1: 0 is opaque, 1 is invisible. It receives the draw result as x, just like colour. It can produce gradual edges without a hard boundary.

transparency fade = smoothstep(2,4,abs(x))

Draw layer

Select an expression, slider, function call, or list. The first input is required. Add colour, boundary, and transparency with the + control, in any order. Later draw layers paint over earlier ones.

draw(rings)
draw(distance(x,y)) {colour=warm, boundary=disc, transparency=fade}
draw(rings) {visible=False}

Defaults are grayscale x~x~x, no restriction, and full opacity. Drawing a list creates one layer per item, starting at index 0. Colour and transparency mapping happen separately for each item.

Curve example

expression curve = y-sin(x)
boundary nearCurve = 0.04-abs(curve)
colour ink = 30~80~180
draw(curve) {colour=ink, boundary=nearCurve}

Lists & points

List

Choose More data > List. A list holds scalar expressions. Indexing starts at 0; .length gives the item count. Scalars broadcast, and two lists operate element by element with equal lengths.

list values = [1,2,3]
list squares = [c^2 for(c=1,10)]
expression first = values[0]
expression shifted = values+10
expression weighted = values*[2,3,4]
expression count = values.length

Shifted evaluates to [11,12,13]; weighted to [2,6,12]. A named list passed to a function remains one list argument. Nested lists and point-valued list items are not supported yet.

Summation & product

expression series = sum(i=1~40){sin(i*x)/i}
expression factorial = prod(i=1~5){i}
list totals = sum(i=1~3){[i,2*i]}

Visit the lower bound, add 1, and continue while the index is at most the upper bound. Fractional bounds and coordinate-dependent bounds are allowed; use floor explicitly for integers. Indices are local to the body. Empty sums return 0; empty products return 1. List results are accumulated element by element, so totals is [6,12], not 18.

In Standard, type sum or prod, enter i=1 in the lower slot, press Up for the upper limit, then Right for the parenthesized body.

Point

Choose More data > Point. Points can be dragged or fixed, coloured, hidden, and linked to a value at their coordinates. Labels and points are included in image exports.

function sample(a,b) = a^2+b^2
point focus = [2,3] {draggable=True, visible=True, colour=default, link=sample, show_label=True}
expression horizontal = focus.x
expression vertical = focus[1]
expression moved = offset(x,y)[0]

.x and [0] select the first component; .y and [1] select the second. These also work on point-returning function calls. Point addition and multiplication work component by component. A point passed to another function fills two successive scalar parameters in x-then-y order.

Syntax & naming

Use + - * / ^ for arithmetic. Powers associate right to left: 2^3^2 is 512; (2^3)^2 is 64. 2sin(x) and 3(x+1) use implicit multiplication. Constants are pi and e.

Fractions accept a/b, frac(a,b), and frac{a}{b}. LaTeX such as \frac{a}{b}, \sqrt{x}, and \operatorname{hypot}(x,y) can be pasted. Multiplication displays as a centred dot. Group a negative exponential as e^(-x^2).

Piecewise conditions

expression band = {x<0:-1,x=0:0,1}
expression masked = {disc:radius}

Conditions are checked left to right. The final value is an optional fallback; without it, unmatched input is undefined. Comparisons are < <= > >= = == !=. A boundary ID can be a condition. Property braces after a declaration use named assignments; piecewise braces inside a formula use condition:value pairs.

Names & recursion

IDs use letters, digits, and underscores; start with a letter or underscore. Values (expressions, sliders, functions, and lists) share a namespace. Exact duplicates there are errors. Reusing an ID in another namespace, such as a colour, gives a yellow naming warning. Built-in names and coordinates are reserved. Known global IDs display upright; coordinates and local parameters stay italic.

expression repeated = repeated+1

Recursive references return 0 when max recursion depth is reached. This example counts reference expansions. Recursive work can grow very quickly; see Limits below.

Folders & comments

folder Lighting = {
  // A comment before the next item
  expression glow = e^(-x^2-y^2) // inline comment
}

Folders can nest and their names may contain spaces. Drag rows to change order or move into a folder. Folders load collapsed; closing one does not remove its contents. Blank lines and comments are preserved in Text view.

Settings

All settings are optional. These are their defaults. Formulas are allowed for graph bounds and aspect ratio. Invalid angle-mode text falls back to radians.

set x_min = -10
set x_max = 10
set y_min = -10
set y_max = 10
The configured graph region. Export captures this region rather than the current pan and zoom.
set ensure_square_grid = True
Keep the chosen grid proportions, adjusting bounds to fit. Invalid bounds warn in this mode and error when it is off.
set aspect_ratio = 1:1
Target width:height. Select a preset or enter two scalar formulas.
set draw_only_inside_boundary = False
Clip rendering to the configured rectangular region. Independent of a draw layer's boundary.
set show_coordinate_grid = True
Master visibility switch for grid, axes, and their numbers.
set show_grid = True
Show the coordinate grid lines behind the graph.
set show_x_axis = True
set show_y_axis = True
Show each axis. Hiding an axis also hides its numbers.
set show_x_numbers = True
set show_y_numbers = True
Show coordinate labels independently of grid lines.
set max_recursion = 100
Maximum nested reference depth before returning zero.
set max_list_size = 10000
Maximum elements per list. Larger lists are undefined and blue-flagged, not truncated.
set angle_mode = radians
Use radians or degrees for circular trig inputs and inverse outputs, including atan2. Hyperbolic functions are unchanged.
set background_color = 0
Default background, or replace 0 with a colour ID for a solid background sampled at (0,0).
set unbounded_decimal_places = 3
Displayed fractional digits for unbounded time. Time accumulation keeps its internal precision.
set random_seed = 1
Scene seed for random. The dice button changes it; copying text preserves it.

Workspace & files

Standard edits the same scene as visual blocks. New line creates an expression; its type menu switches to another data type. Enter inserts a row immediately below the current row, inside the same folder. Search, type filters, sorting, and dependency views help navigate larger scenes.

Text holds an editable draft. Apply to graph compiles it and keeps you in Text view. Reload from graph discards that draft after confirmation. Switching to Standard with unapplied edits offers Apply or Discard. Ctrl/Cmd-Z and Ctrl/Cmd-Y work inside and outside fields; time playback and slider movement do not fill undo history.

Graph menu contains New, Save, Load, and Export. Save stores a named scene and compact thumbnail in this browser; Load opens the library. Export downloads a PNG of the configured graph region with visible points and labels. Save is highlighted after unsaved edits.

Navigation: drag the graph to pan, scroll to zoom, and drag the divider to resize the editor. The gear opens settings; the keyboard button opens a calculator pad and variable library. On phones, the graph sits above the editor.

Backups: browser saves are not cloud backups. There are up to 60 slots, subject to storage quota. Clearing site data or moving domains does not transfer them. Keep a copy of the complete Text view for important work.

Limits & flags

Red means a syntax, reference, or settings error. Yellow is a warning, such as ambiguous naming. Blue indicates expensive or oversized work; the graph may be slow or fail to render. Green means validation passed, not a guarantee about every coordinate. Click a flag for details.

Domains still matter: division by zero, negative square roots, and invalid logarithms have no finite result. CPU calculations and GPU floating-point calculations have different precision; extreme values can overflow. Dense patterns may alias at screen resolution.

Scalar graphs need WebGL; lists and reductions need WebGL 2. Coordinate-dependent loops and large recursive scenes can exceed GPU limits or stall the page. Complexity estimates and blue warnings are not a reliable execution-time limit.

Lepton currently supports one-dimensional scalar lists and two-component points. It does not yet include spreadsheet import, statistical fitting, matrix operations, or a general-purpose loop language.
